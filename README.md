# MIT-App-Inventor-Project-Calculator
This project is my study about how to use MIT App Inventor. It features a basic calculator that uses a spinner as its operational menu, rather than traditional buttons. The design is pretty basic as it is my first time doing a project in such platform, and I would say that it was both exhilirating and frustrating at the same time LOL. But I managed to pull this project off and will continue its progress as I explore more possibilities and do more improvements to this side project. Thank you so much.
